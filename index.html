    ☁️ เชื่อม Google Sheet (สำรอง + ราคาสด)

    เก็บข้อมูลทั้งหมดไว้บน Google Sheet ชื่อ Wealth ของคุณ — เปิดจากเครื่องไหน มือถือ/คอม ก็เห็นข้อมูลชุดเดียวกัน และดึงราคาหุ้น/ทอง/ค่าเงินสดจากชีต (GOOGLEFINANCE) อัตโนมัติ เหมือนแอปสุขภาพที่ซิงค์ขึ้นคลาวด์

    ยังไม่ได้เชื่อม
    วิธีตั้งค่าครั้งแรก (ทำครั้งเดียว ~2 นาที)
    1. เปิด Google Sheet ชื่อ Wealth → เมนู Extensions → Apps Script
    2. วางโค้ดจากไฟล์ Wealth-AppsScript-Code.gs ที่ผมส่งให้ → กด 💾 Save
    3. Deploy → New deployment → Web app · Execute as: Me · Who has access: Anyone
    4. อนุญาตสิทธิ์ แล้วก๊อป Web app URL (ลงท้าย /exec) มาวางช่องด้านบน → กดเชื่อม
    5. แก้โค้ดภายหลัง: Deploy → Manage deployments → แก้ version เป็น New version ทุกครั้ง
